# GaemiRanger

한국투자증권 Open API로 만드는 1인용 국내주식 트레이딩 웹사이트입니다.

> 지금은 **기획 단계**입니다. 아직 동작하는 코드는 없습니다.

## 무엇을 만드나

- 내 포트폴리오와 시장을 **히트맵**으로 한눈에 보고
- 시세·차트·호가를 보고, 매수·매도·취소를 하고
- **손절·익절 같은 규칙**을 등록하면 프로그램이 그 규칙대로 실행하는 사이트

장중에 감으로 사고파는 대신, 미리 정한 규칙대로 움직이게 하는 것이 목표입니다.

## 만드는 순서

1. **1부: 모든 기능을 손으로 할 수 있게** 만듭니다. 메뉴, 버튼, 입력칸만으로 전부 됩니다.
2. **2부: 같은 기능을 AI(Claude)가 할 수 있게** 합니다. 대화로 화면을 바꾸고, 손절 폭을 함께 따져 보고, 규칙 초안을 만들어 줍니다.

### 원칙

- 기능 하나는 서버 도구 하나와 화면 하나로 만듭니다. 2부의 AI는 새 기능이 아니라 같은 도구를 대신 부릅니다.
- AI가 없어도 모든 기능이 동작합니다. 모든 화면은 메뉴로 갈 수 있습니다.
- AI는 화면 이동과 조회만 바로 합니다. 주문과 규칙 등록은 제안만 하고, 사람이 확정해야 실행됩니다.
- 주문 한도와 안전장치는 서버가 강제합니다. 누가 요청했든 같은 검사를 거칩니다.
- 모의투자로 먼저 개발하고 검증한 뒤 실전으로 전환합니다.

## 화면 (메뉴)

| 메뉴 | 내용 |
|---|---|
| 시장 | 시장 히트맵(코스피 시가총액 상위 50), 내 포트폴리오 히트맵(크기 = 내 비중), 지수·환율·내 자산 요약 |
| 종목 | 검색, 차트, 호가, 종목 정보, 관심종목 |
| 주문 | 매수·매도, 확인창, 정정·취소 |
| 계좌 | 예수금, 보유종목, 체결 내역 |
| 규칙 | 손절·익절·추적 손절, 조건부 매수, 가격 알림, 규칙 목록 |
| 기록 | 모든 주문·규칙 발동·설정 변경 기록 |
| 설정 | 주문 한도, 비상 정지, 알림, 모의·실전 전환, 로그인 |

색은 상승 초록, 하락 빨강입니다.

## 기술 (계획)

- 백엔드: Python, FastAPI, SQLite
- 화면: React, Vite, TypeScript
- 알림: 텔레그램 봇
- 증권 API: [한국투자증권 Open API](https://github.com/koreainvestment/open-trading-api)
- AI (2부): Claude
